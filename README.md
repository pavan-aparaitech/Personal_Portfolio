# Pavan Mali - Portfolio

A modern, interactive portfolio website built with React, TypeScript, and Tailwind CSS.

## Features

- **Responsive Design** - Fully responsive across all devices
- **Smooth Animations** - Beautiful fade and scroll animations
- **Interactive Components** - Engaging user experience with interactive elements
- **Dark/Light Support** - Modern UI with gradient backgrounds
- **Typewriter Effect** - Dynamic text animation in hero section
- **Code Syntax Highlighting** - Visual code blocks with syntax colors
- **Smooth Scrolling** - Seamless navigation between sections

## Tech Stack

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS, PostCSS
- **Build Tool**: Vite
- **Icons**: Lucide React
- **Development**: ESLint, TypeScript strict mode

## Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint

# Type checking
npm run typecheck
```
